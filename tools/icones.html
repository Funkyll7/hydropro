Fabrique d'icônes

Le dépôt ne contient aucune image binaire : la marque est un fichier SVG, assets/img/favicon.svg, qui sert d'icône partout où le navigateur l'accepte — onglet, manifeste, écran d'installation sous Android.

Deux endroits ne l'acceptent pas : l'écran d'accueil d'un iPhone, qui réclame un PNG, et les écrans de lancement Android, plus nets avec un PNG de 512 px. Cette page les fabrique : elle redessine le logo dans un canvas et propose chaque taille au téléchargement.

Le fichier assets/img/favicon.svg reste la source de vérité. Si vous le modifiez, reportez la modification dans dessiner() ci-dessous — le dessin est refait en code plutôt que chargé depuis le SVG, parce qu'un canvas alimenté par une image SVG externe est marqué « pollué » par certains navigateurs et refuse alors toDataURL().

Enregistrez les fichiers téléchargés dans assets/img/ sous les noms indiqués, puis, pour qu'ils servent réellement :

  1. décommentez la ligne apple-touch-icon de index.html ;
  2. ajoutez-les au tableau icons de manifest.webmanifest ;
  3. ajoutez-les à la liste COQUE de sw.js, faute de quoi ils manqueront hors ligne — et un fichier absent de cette liste fait échouer toute l'installation du cache.
